### 1. Create the project

Open your itch.io dashboard and choose:

```
Create new project
```

Use:

```
Title: Woodland Outpost
Project URL: woodland-outpost
Classification: Games
Kind of project: Downloadable
Release status: In development
```

For this first release, I recommend:

```
Pricing: $0 or Donate
Suggested donation: $2
```

Players can still download it for free, while optionally supporting development. itch.io also supports disabling payments entirely if you prefer. [itch.io pricing options](https://itch.io/docs/creators/pricing?utm_source=chatgpt.com)

### 2. Add the short description

Use:

> Gather resources, build your woodland camp, and complete your cabin before winter arrives.

### 3. Upload the build

Upload:

```
WoodlandOutpost-v0.1.0-Windows-x86_64.zip
```

After uploading, mark:

```
This file is for Windows: On
```

Do not mark it as a demo unless you specifically want this build presented as a demo.

A versioned ZIP per supported platform is the normal itch.io release structure. [itch.io creator guide](https://itch.io/docs/creators/getting-started?utm_source=chatgpt.com)

### 4. Add metadata

Recommended genre:

```
Strategy
```

Recommended tags:

```
Pixel Art
Survival
Resource Management
Building
Singleplayer
2D
Atmospheric
Short
```

Set:

```
Made with: Godot
Average session: About a half-hour
Languages: English
Inputs: Keyboard
```

Adjust the average session if your completed run normally takes longer.

### 5. Keep it private initially

Set visibility to:

```
Draft
```

Then choose:

```
Save & view page
```

New itch.io pages are private by default, allowing you to test and style them before publication. [itch.io publishing guide](https://itch.io/docs/creators/getting-started?utm_source=chatgpt.com)

### 6. Test the itch.io download

From the private page:

1. Download your ZIP.
2. Extract it into a new empty folder.
3. Launch `WoodlandOutpost.exe`.
4. Verify that the `.pck` and README are included.
5. Test Settings from the title menu.
6. Start a game and test Pause.
7. Confirm the icon appears correctly.

Keep the project in Draft for now. Next we’ll prepare the polished itch.io page description, cover image, screenshots, and page colors before making it public.
