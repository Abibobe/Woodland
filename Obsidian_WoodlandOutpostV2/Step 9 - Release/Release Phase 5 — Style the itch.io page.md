From the private project page, choose:

```
Edit theme
```

Use this palette:

```
Page background:    #0b1712
Content background: #13231d
Text:               #f2e7c9
Links:              #f2d16b
Buttons:            #263a32
Button text:        #f2e7c9
```

Recommended settings:

```
Background image: None
Background repeat:  No repeat
Content width:      Default
Font:               Sans-serif
```

Avoid placing a gameplay screenshot behind the page content—it makes text harder to read and competes with the cover. The dark forest-green background will match the game while keeping the page clean.

After saving the theme, check:

- The title is readable.
- The cover is not cropped unexpectedly.
- Description headings are clear.
- Download button has enough contrast.
- All five screenshots open at full size.
- The Windows ZIP is visible and marked for Windows.
- The project remains in **Draft**.

Once the private page looks correct, the last step is publication.
