
Before pressing Publish, verify:

- Cover image is visible.
- Description includes the development notice.
- Five screenshots are uploaded.
- ZIP is marked for Windows.
- Price is `$0 or Donate`.
- Release status is `In development`.
- Downloaded ZIP launches correctly.

Then open:

```
Edit game → Visibility & access
```

Change:

```
Draft → Public
```

Save the page.

After publishing, open the public URL in a private/incognito browser window and verify:

1. The page is publicly accessible.
2. The download button works.
3. The correct ZIP filename appears.
4. Windows is displayed as the supported platform.
5. Images and description render correctly.

And that’s it: **Woodland Outpost v0.1.0 is officially released.** 🌲🔥

Keep the same itch.io project page for future versions. When `v0.1.1` is ready, upload the new ZIP and replace the old build rather than creating another project page.
