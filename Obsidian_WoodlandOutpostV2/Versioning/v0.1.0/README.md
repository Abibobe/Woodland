WOODLAND OUTPOST
Version 0.1.0

Survive. Gather. Build.


OBJECTIVE
Gather wood, stone, and food to develop your camp before winter arrives.
Build the campfire, foundation, and completed cabin to survive.


CONTROLS
WASD / Arrow Keys    Move
E                    Gather or interact
Escape               Pause / return
Enter                 Activate selected menu button
Alt + Enter           Toggle fullscreen


INSTALLATION
1. Extract every file from the ZIP archive into the same folder.
2. Run WoodlandOutpost.exe.
3. Keep WoodlandOutpost.pck beside the executable.


SETTINGS AND SAVE DATA
Audio, display, and tutorial preferences are stored in Godot's user data
directory. These preferences remain available after the game is closed.


TROUBLESHOOTING
If Windows displays a security warning, choose the option to view more
information and run the game only if you downloaded it from the official
Woodland Outpost page.

If the game does not start, confirm that the EXE and PCK files were extracted
and remain together in the same directory.
